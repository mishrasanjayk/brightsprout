# BrightSprout

*Making the next gen smarter and healthier.*

A clickable prototype of a healthy-habits app for kids ages 2 to 14. Kids earn Stars for eating well, moving, family time and learning, and spend them on rewards their family chooses. Screen time is never blocked; healthy habits are simply rewarded more.

Live prototype: https://mishrasanjayk.github.io/brightsprout/

Data is stored only in the browser on each device (no accounts, no tracking).

## iPhone app

The `ios/` folder builds BrightSprout as a native iPhone app with real Screen Time app blocking. It uses this same `index.html`. See [ios/README.md](ios/README.md).
